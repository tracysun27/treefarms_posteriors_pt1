# CS 671D Fall 2024 Final Project

This was some code I wrote for independent study in Spring 2025. Building upon my previous work for my CS 671D final project. The code in this repository gets the trees in the Rashomon set for some different regularization levels and finds and saves their objectives for comparison with that of MAPTree.
The original repository for treefarms that I built upon and used is here: https://github.com/ubc-systopia/treeFarms 
The MAPTree part of the code is here: https://github.com/tracysun27/treefarms_posteriors
